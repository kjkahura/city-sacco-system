# AGENTS.md

The instructions for coding agents working in this repository are in [CLAUDE.md](CLAUDE.md). They apply to every agent, whatever its name; this file exists so tools that look for `AGENTS.md` find them.

Start with:
1. `CLAUDE.md`: where the code is, how to run it, and the rules that are not negotiable.
2. `platform/docs/ARCHITECTURE-ESSENTIALS.md`: the architecture in two pages.
3. `platform/README.md`: the full design, section by section.
4. `platform/docs/audits/NEXT.md`: what remains to be done; mark items done there.
